# Исследование контекстного байасинга SODA

Эти результаты относятся к проверенным моделям и маршрутам живых прогонов. Они объясняют, почему восстановление терминов вынесено в отдельный пост-слой, а не в движок SODA.

1. В native API SODA найден контекстный байасинг: `UpdateRecognitionContext` с protobuf-списком фраз и весом boost. Доказано на en-US: вес **1.5** улучшает распознавание терминов — на живом голосе term recall вырос с **24/66 до 43/66**, micro WER снизился с **0.576 до 0.192**. На ru-RU ни один маршрут байасинга не работает: **80 контролируемых прогонов** набора A и **30 кириллических прогонов A7** на живом голосе дали ноль новых правильных терминов. Это ограниченный отрицательный результат для проверенных моделей и маршрутов, а не доказательство невозможности вообще.
2. ru-RU спонтанно выдаёт латиницу: `Up`, `System D Unit`, `Python`, `genix`, `pythonka`, а в PARTIAL даже `exitbox`. Модель не заперта в кириллице: пост-слой обязан сохранять правильную латиницу, а не переводить всё подряд.
3. На en-US байасинг не всесилен: `onnx` превратился в `Annex`/`Onyx` во всех **16 прогонах**, а `docker compose up` — в `docker compose app`. Гипотезы, которые не проверялись: фонетические респеллинги в словаре байасинга и добавление полных команд вместо отдельных слов.
4. Наблюдаемые реальные ошибки ru-RU на живом голосе (бейзлайн), ставшие семенем словаря пост-слоя: `докер кампоуз/кампоусаб/компост/компоус/компас/компаузап`, `комит/коммит`, `инженекс/genix`, `System D Unit / System de Unit / System Di Unit`, `пальтон/pythonka`, `осинка вейт`, `пакман/яй`, `экзит бокс/quid proxy`.
5. Контрольная обычная русская фраза без терминов не получила словарных вставок даже при boost **4**. Омонимы «Питон — это змея, а сода стоит на кухонной полке» распознались идеально без всякого байасинга (**WER 0**). Пост-слой не должен «исправлять» такие слова.
6. Отдельная нерешённая проблема, не входящая в пост-слой: на одной записи **A6-natural** SODA не выдала FINAL вообще, только PARTIAL. Это вопрос endpointing/финализации; в рамках пост-слоя он не исправляется.
7. Существует **175 дословных транскриптов** живых прогонов с эталонами. Если пользователь передаст `live-results-v2.md`, его можно использовать как расширенный регрессионный набор. В текущую работу файл не передавался; использовались фикстуры из задания.
